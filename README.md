# 修仙世界 XiuxianWorldMod

《修仙世界》是 DroneFlames（0.33）的修仙题材模组：**正道仙门 vs 玄魔道**双阵营，纯沙盒、无正式胜负终局。所有单位从零原创，所有界面为修仙专属设计。

- **修炼成长**：弟子从**凡人**起步，经炼气、筑基、金丹、元婴、化神直至渡劫；修炼全自动托管（三档），分丹阁按修炼速度分配丹药；弟子有灵根/体质/悟性/气运四维与天骄五档，寿元、坐化、心境、丹毒俱全
- **宗门系统**：宗门 6 级与宗门影响力决定弟子上限；招募候选池（只招最低阶弟子、高阶全靠自己修炼突破）；职位任命、师徒传承、宗门道统与功法参悟两套成长线（90×2 + 30）
- **修仙独有玩法**：宗门大比（可亲自选派弟子上擂台实战）、天骄榜与天骄挑战、秘境三层探索、坊市拍卖、灵兽收服/繁殖/坐骑、灵脉争夺、护山大阵、炼丹（丹方/开炉/炸炉）与炼器、洗髓池、传送阵、云舟远征
- **突破与渡劫**：金丹以上突破半自动、需玩家确认；渡劫九道天雷；走火入魔事件化；强者可**自创功法**入传承栏，创法者陨落后抄本可能被夺
- **正魔差异**：魔道有嗜血/血祭与更高的阵法强度，正道治疗与突破更稳；气运之子全图唯一
- **专属 UI 与表现**：从零设计的山门枢纽（总览/弟子/宗门事务/库藏功法/设置五分类双层结构）、修仙纪年、突破/渡劫程序化动画与 44 部功法绝技特效、原创五声音阶 BGM

## 安装

1. **游戏内导入**：在游戏的模组管理里选择「导入」，选中下载的 `.dfmod` 文件，启用《修仙世界》。
2. **文件夹放入**：把 `.dfmod` 放到手机的 `Download/DroneFlamesMods` 目录，再在游戏内导入/启用。
